## Plan on 75 minutes

- 10 minutes: read
- 45–60 minutes: prompt, inspect, and refine
- 15 minutes: verify and explain

## See how agentic setup is supposed to work

- [Agentic setup](https://storybook.js.org/docs/10.5/ai/setup)
- [Storybook installation](https://storybook.js.org/docs/10.5/get-started/install)

Agentic setup is a preview capability for React with the Vite builder. It accelerates codebase analysis,
preview configuration, mocks, stories, play functions, verification, and MCP installation. It does not
remove the need to understand those parts.

## Give the agent a bounded job

1. Open your coding agent at the repository root. The official documentation currently proposes:

   ```text
   Set up Storybook for me with npm create storybook@latest and follow its instructions precisely
   ```

2. For this pinned pnpm course, use the constrained version below so the agent does not switch package
   managers, change sibling frameworks, or silently move beyond Storybook 10.5:

   ```text
   Review and finish setting up Storybook for packages/react using React, Vite, pnpm, and Storybook
   10.5.5. Follow Storybook's official agentic setup instructions precisely. Keep every Storybook
   package on 10.5.5, do not edit sibling packages, preserve the existing customer scenario, tag new
   stories ai-generated, and stop to explain any destructive or cross-workspace change before making it.
   Run the React Storybook tests, type checker, and static build when finished.
   ```

3. Require the agent to produce its setup plan before editing. Compare that plan to the existing
   `main.ts`, `preview.tsx`, `vitest.config.ts`, stories, and package scripts.
4. Let it improve one bounded area, such as missing component JSDoc, a portal root, or a story state.
   Reject unrelated rewrites.
5. Review every changed line. Keep `ai-generated` tags until Day 3 validates the stories.

## Review the diff like you own it

```sh
pnpm --filter @demo/react typecheck
pnpm --filter @demo/react exec vitest run --project=storybook
pnpm --filter @demo/react build-storybook
git diff --check
```

In your progress file, record one useful agent observation, one suggestion you rejected or constrained,
and why the final change is trustworthy.

## Try this explanation

Put this in your own words: **Where does Storybook AI save time, and where does engineering judgment
still matter?**
