      <span className="setup-step__label">Developer tools</span>
      <h2>Install Git, Node.js 20, and pnpm</h2>
      <div className="setup-step__intro">
        Use a terminal in VS Code. The commands in this course use a
        macOS/Linux-style shell. Windows users can use WSL or adapt the file
        commands for PowerShell.
      </div>

      Install Git from the{' '}
      <a href="https://git-scm.com/downloads">official Git downloads</a>. On
      macOS or Linux, install `nvm` from the{' '}
      <a href="https://github.com/nvm-sh/nvm#installing-and-updating">
        nvm installation guide
      </a>
      . On Windows, use your company's approved version manager or the{' '}
      <a href="https://nodejs.org/en/download">Node.js download page</a> to
      install Node 20.

      ```sh
      git --version
      nvm install
      nvm use
      node --version
      corepack enable
      corepack prepare pnpm@10.19.0 --activate
      pnpm --version
      ```

      <div className="setup-success">
        <strong>Expected versions</strong>
        <span>
          <code>node --version</code> starts with <code>v20</code> and{' '}

    <span className="setup-step__number" aria-hidden="true">5</span>
    <div className="setup-step__body">
      <span className="setup-step__label">Health check</span>
      <h2>Prove the repository works before you change it</h2>
      <div className="setup-step__intro">
        A failure now is a setup issue. A new failure after Day 1 is more likely
        to come from your change.
      </div>

      ```sh
      pnpm check
      pnpm dev
      ```

      Keep <code>pnpm dev</code> running. Open the Hub at{' '}
      <code>http://localhost:6006</code> and the React Storybook at{' '}
      <code>http://localhost:6007</code>.

      If ports 6006–6011 are busy, stop the conflicting process or shift the
      full range:

      ```sh
      STORYBOOK_PORT_OFFSET=100 pnpm dev
      ```

      With that offset, the Hub uses <code>http://localhost:6106</code> and the
      React Storybook uses <code>http://localhost:6107</code>.

      <div className="setup-success">
